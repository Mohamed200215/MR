# Merkeregister — UX Case Study

A concept redesign of Fiskeridirektoratet's Merkeregister vessel registration flow on Altinn.

## Deploying to GitHub Pages

1. Create a new repository on GitHub (e.g. `merkeregister-case-study`)
2. Upload the contents of this folder to the repository root:
   - `index.html`
   - `images/` folder (with all 5 screenshots)
3. In the repo, go to **Settings → Pages**
4. Under "Source", select the `main` branch and `/ (root)` folder, then Save
5. GitHub will give you a live URL, typically:
   `https://<your-username>.github.io/merkeregister-case-study/`
6. It may take 1-2 minutes to go live after the first deploy

No build step needed — this is a single static HTML file with local images.
